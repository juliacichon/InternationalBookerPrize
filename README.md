This dashboard presents a statistical analysis of the International Booker Prize. The data was collected and imported into SQL by me.

The dataset covers 11 editions of the award, from 2016 to 2026, and includes 143 nominated books and 122 authors from around the world.

The analysis points:
- the country of origin,
- original language, author,
- translator or translators,
- English publisher,
- year of original publication and
- waiting time between the original publication and the book’s nomination for the award
for each nominated book across all award years.

During the project, I focused on creating interactive tooltips for each chart.

The analysis was made as a part of data analysis course by Kajo Rudziński, kajodata.com

The dashboard graphics were designed with the help of Canva.
